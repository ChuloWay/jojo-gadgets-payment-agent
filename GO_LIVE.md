# Go-live note

This build is a test-mode demonstration for Jojo Gadgets. Before real customers use it, Uchenna needs to adopt generated checkout links as a supported payment path and keep the agent synchronized with the shop's handwritten stock book and walk-in sales. Arbitrary bank transfers, temporary virtual accounts, delivery, refunds, trade-ins, installments, and disputes still require an owner-operated process.

Production readiness requires live Paystack credentials in a managed secret store, verified Paystack webhooks feeding the same idempotent payment-finalization path, a delivered owner-notification channel, database backups and recovery drills, monitoring and alerts, retention rules for customer identifiers and provider payloads, and a documented reconciliation process for ambiguous provider outcomes. Access to stock and order data should be limited by role and every manual correction should be audited.

Before launch, run a controlled pilot with low-value inventory. Measure verification time, owner-review rate, expired payment windows, competing successful payments for the last unit, duplicate tool calls, inventory mismatches, and failed notification delivery. Confirm the warranty attached to each listed device because three months is the default but can vary by acquisition deal. The assistant must continue to say that only reference verification confirms payment, even when a customer supplies a convincing screenshot or insists that a transfer succeeded.
